# Repotray releases

Android builds of [Repotray](https://repotray.app), a mobile client for GitLab, GitHub, Gitea / Forgejo / Codeberg, Azure DevOps and Bitbucket Cloud.

Download the latest APK from [Releases](https://github.com/docaohieu2808/repotray-releases/releases/latest). Android 9 or newer, arm64.

This is the temporary download channel while the Google Play listing is in preparation. Every APK is signed with the same key; the SHA-256 of each file is in its release notes.

- Changelog: https://repotray.app/changelog/
- Support: https://repotray.app/support/
